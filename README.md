# AION 2 Checklist

Daily and weekly checklist for AION 2 Global, with character lookup and a
where-to-get-it item search. Progress is saved in each visitor's browser
(localStorage). There are no accounts and no database.

- **Checklist:** daily and weekly tasks, one checkbox each, per character. They
  clear automatically at the reset: 07:00 UTC daily and Wednesday 07:00 UTC
  weekly, the same on every Global region. The header shows countdowns to the
  next resets and to Shugo Festival, Dimensional Invasion and Spacetime Rift.
- **Characters:** search by name and region through NCSOFT's official
  character API, which gives the portrait, class, level, combat power and item
  level. You can also add a character by name only. Each character keeps its
  own progress.
- **Items:** search about 4,600 items (materials, consumables, skins, titles)
  with their official icons and descriptions. Hand-written shop and source
  info lives in `public/data/sources.json`, and visitors can pin items and
  keep their own notes.

## Run it locally

Needs Node 18 or newer. The code is TypeScript; the only dependencies are
`typescript` and `@types/node`, both dev-only. The site itself still ships as
plain ES modules with no runtime dependencies.

```sh
npm install
npm start            # builds, then serves http://127.0.0.1:3005
npm run watch        # recompile the browser code on save (run npm run serve alongside)
npm run typecheck    # both programs, no output
```

## How it fits together

| Path | What it is |
| --- | --- |
| `src/server.ts` | Serves `public/` and relays `/api/servers`, `/api/search`, `/api/character` and `/api/item` to NCSOFT. NCSOFT rejects browser requests from other sites, so lookups have to go through here. Lookups are cached and rate-limited per visitor. Compiles to `dist/server.js`. |
| `src/client/` | The browser code. Compiles to `public/js/`, which is build output and isn't committed. |
| `src/client/tasks.ts` | The default task list. |
| `src/scripts/` | The game-data builders below. Compile to `dist/scripts/`. |
| `public/` | The site nginx serves: HTML, CSS, data, icons, and the compiled `js/`. |
| `public/data/sources.json` | Where-to-get-it entries. Edit this to add shops and sources. |
| `public/data/items.json` | The item index, generated by `npm run build:items`. |
| `public/icons/` | Task icons from NCSOFT's game-data CDN, shrunk to 128px WebP. |
| `deploy/` | The nginx server block and pm2 config. |
| `tsconfig.*.json` | Two programs sharing `tsconfig.base.json`: `client` (DOM, emits to `public/js`) and `server` (Node, emits to `dist`). Both strict. |

### Refreshing game data

- `npm run build:items` rebuilds the item index. It takes the item IDs from
  NCSOFT's Taiwan item dictionary and the English names from the Global item
  API, at 5 requests a second. Responses are cached in `scripts/.cache`, so
  reruns only fetch new items. Gear isn't included, because Taiwan's gear IDs
  don't exist on Global.
- `npm run build:icons`, then `python scripts/shrink-icons.py` (needs
  Pillow), fetches any new icons added to `src/client/icons.ts`.

Both run the compiled scripts, so run `npm run build` first.

## Deploy (nginx + pm2)

1. **DNS:** add an `A` record for `aion` pointing at the server's IP.
2. **Code:** clone the repo to `/opt/aion2-checklist`:
   `git clone https://github.com/taylorjohannsen/aion2-checklist /opt/aion2-checklist`.
3. **Build:** in that folder, run `npm ci && npm run build`.
4. **Relay:** run `pm2 start deploy/ecosystem.config.cjs && pm2 save`. It
   listens on `127.0.0.1:3005`.
5. **nginx:** copy `deploy/nginx.conf` to
   `/etc/nginx/sites-available/aion.taylorjohannsen.com`, symlink it into
   `sites-enabled`, then run `sudo nginx -t && sudo systemctl reload nginx`.
6. **HTTPS:** run `sudo certbot --nginx -d aion.taylorjohannsen.com`.

To ship an update:

```sh
cd /opt/aion2-checklist && git pull && npm ci && npm run build && pm2 restart aion2-checklist
```

The build has to run on every update, since the browser code is compiled
there. The restart only matters when `src/server.ts` changes; nginx serves the
static files directly.
